# Evolution-public-goods-altruism
Scripts used for the manuscript The evolution of Public goods altruism

There are two scripts:
1) the appendix is a plotting function designed to plot multiple matrix on the same figure and just needs to be called at the beginning of the main script.
2) the script used to draw figures of the supplementary document. The first algorithm that searches the evolutionary steady-state is fully detailed. All the other ones but the last two are variations of the first one, where either the level of investment I or the level of local competition R_LT/Fst changes. The last two algorithms are used to find numerically the thresholds for altruism monomorphism and altruist/cheater polymorphism. These thresholds (based on the exact solution) are then compared to the approximation derived analytically to show which variables impact its accuracy (and to confirm that the approximation is accurate for a wide range of the parameter space).
